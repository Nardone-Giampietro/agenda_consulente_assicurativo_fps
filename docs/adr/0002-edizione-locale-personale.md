# Edizione locale personale per un solo computer

Su scelta dell’utente, l’edizione locale di Agenda WA è destinata a un solo utilizzatore e un solo computer: dati personali indipendenti, nessuna condivisione o sincronizzazione e accesso protetto da una password scelta dall’utilizzatore. L’interfaccia resta nel browser e il primo ambiente supportato è un Chromebook con Linux già predisposto; la consegna consiste in un file `.deb`, ottenibile anche senza rete sul dispositivo destinatario, e il funzionamento dell’applicazione è interamente offline. Questa edizione viene sviluppata nel branch `codex/versione-locale`, conservando separatamente la versione web precedente, perché il modello personale consente di semplificare la gestione locale ma rinuncia all’uso della stessa agenda da più dispositivi o utenti.
